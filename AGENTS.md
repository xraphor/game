# Instruções para o Codex

Este repositório pertence ao usuário e será usado para desenvolver um jogo.

## Escopo
- Siga o pedido atual do usuário para escolher gênero, plataforma e engine. Esses detalhes ainda não foram definidos.
- Se não houver uma descrição do jogo, pergunte qual jogo o usuário quer criar antes de escolher uma engine ou implementar mecânicas.
- Desenvolva uma primeira versão realmente jogável, depois expanda de acordo com o pedido.
- Não declare que existe um executável, publicação ou recurso sem verificar o resultado.

## Desenvolvimento
- Inspecione os arquivos existentes antes de alterar o projeto.
- Mantenha código organizado e instruções de instalação e execução no README.
- Não armazene segredos, tokens, dependências instaladas ou arquivos temporários no Git.
- Use recursos originais ou licenciados e documente suas fontes quando necessário.
- Verifique controles, início da partida, reinício e condições de vitória/derrota quando aplicáveis.
- Execute as verificações disponíveis e informe limitações concretas.
- Ao terminar, explique em português o que foi criado e como jogar.
