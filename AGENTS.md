# NUKE PC
O pedido atual substitui completamente o jogo: criar um PC virtual funcional.
Leia README.md e compose.yaml. A base atual e um desktop Linux Ubuntu XFCE em container via Webtop.
Priorize iniciar e validar a sessao real, persistencia de arquivos, terminal, teclado e mouse, reconexao e autenticao. Nao substitua por um desktop simulado em HTML.
Nao declare servidor provisionado, sessao testada ou desempenho garantido sem evidencias.
Nao publique senhas, .env ou portas sem autenticacao. Preserve os dados do usuario. Nao monte socket Docker ou habilite privileged sem necessidade e autorizacao.
Para uma futura VM Windows, documente host com virtualizacao, recursos e licenca necessarios antes de implementar.
Atualize README com comandos verificados e limitacoes. Responda em portugues.
